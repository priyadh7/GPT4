# Personalized Recommendation System

Experiment 4 - 24CS2506 Building Applications using GPT-4

A personalized learning recommendation website built with Flask and Ollama.

## Features
- User profile input
- AI-generated personalized recommendations
- Ranked recommendations with match scores
- Explanation for each recommendation
- Feedback-based recommendation updates

## Technologies
Python, Flask, HTML, CSS, Ollama (Llama 3.2)

## Run
1. Install dependencies: pip install -r requirements.txt
2. Ensure Ollama is running and llama3.2 is installed.
3. Run: python app.py
4. Open http://127.0.0.1:5000
